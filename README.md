# Doki Doki Literature Club - Fan Remake / Vietnamese Version
**App game by VioletMoon (TanTran)**

Dự án Visual Novel Doki Doki Literature Club (DDLC) phiên bản tiếng Việt được tái cấu trúc và phát triển trên Ren'Py Engine.

---

## 🎮 Hướng dẫn cài đặt & Khởi chạy

### 1. Yêu cầu môi trường
* **Ren'Py SDK 7** (khuyên dùng Ren'Py 7.4.11 hoặc 7.5.x)
* Hệ điều hành: Windows, macOS hoặc Linux

### 2. Khởi chạy dự án
1. Tải và giải nén **Ren'Py 7 SDK**.
2. Mở `renpy.exe`, trỏ thư mục Projects Directory tới thư mục chứa dự án này.
3. Chọn dự án và bấm **Launch Project** để chơi thử.

### 3. Đóng gói ra file thực thi (.EXE)
* Nhấp đúp vào file `build_exe.bat` trên Windows để tự động đóng gói dự án thành bản độc lập chứa file `.exe` trong thư mục `dist/`.
* Hoặc mở Ren'Py Launcher, chọn **Build Distributions** -> tích chọn **Windows** -> bấm **Build**.

---

## 📁 Cấu trúc thư mục mã nguồn
* `game/script.rpy`: Điểm bắt đầu trò chơi.
* `game/script-ch*.rpy`: Toàn bộ kịch bản và phân cảnh các chương.
* `game/definitions.rpy`: Định nghĩa hình ảnh, nhân vật, âm thanh.
* `game/screens.rpy` & `game/gui.rpy`: Giao diện và các màn hình menu.
* `game/options.rpy`: Cấu hình game, tên cửa sổ, bản quyền.
